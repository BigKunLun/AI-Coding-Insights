> **状态：第 6 镜（报告那一屏）已录，落 `docs/demo/demo.gif`**，是逐帧真实渲染的
> 报告滚动通览，录法见 [`README.md`](README.md) 的「GIF 是怎么录的」，可一条命令重录。

## 目标

15 秒内让人看明白三件事：**一条命令装上 → 在自己的 agent 里一句话触发 → 出报告**。
不解释原理，不展示配置。

## 硬性约束

- **不能出现任何真实项目名、路径中的用户名、业务词、仓库名。**
  录之前先 `cd` 到一个空目录，终端提示符改成 `~/demo` 一类，或直接用一台干净账号。
- 报告那一屏用 `docs/demo/aci-report-demo.html`（假数据），**不要用你自己的真实报告**。
- 全程中文界面，字号调大（终端 18–20pt），录 1280×720 以上再压。

## 分镜（总长 ~15s）

| # | 时长 | 画面 | 敲什么 / 预期看到什么 |
|---|---|---|---|
| 1 | 0–3s | 干净终端 | 敲 `uvx ai-coding-insights install`<br>预期：打印落位路径（如 `~/.claude/skills/ai-coding-insights/SKILL.md`）+ 「已安装」 |
| 2 | 3–5s | 同一终端 | 敲 `uvx ai-coding-insights install --print`（可选，展示预演不写盘）<br>预期：一段 JSON，含 `target` / `degraded: false` |
| 3 | 5–8s | 切到 agent CLI（Claude Code） | 敲 `/ai-coding-insights`<br>预期：开始扫描、分批、派子代理的进度输出 |
| 4 | 8–10s | 进度快进（加速 4×） | 预期：几行「批次 / 专家 / 合成」进度；**不要停在任何含真实路径的行上** |
| 5 | 10–12s | 终端末尾 | 预期：报告路径 + `姿势分布: …` / `姿态健康态: …` / `成熟度档位: …` 三行 |
| 6 | 12–15s | 浏览器打开报告 | 从横幅（档位 + 四个大数）缓慢下滚到「姿势分布」那一屏收尾 |

## 三家 harness 的触发方式（第 3 镜二选一）

- Claude Code：`/ai-coding-insights`
- Codex CLI：`$ai-coding-insights`
- opencode：`/ai-coding-insights`

若要一条 GIF 覆盖三家，把第 3–5 镜压成三段各 2 秒的并排/连切，右上角打 harness 名字标。
